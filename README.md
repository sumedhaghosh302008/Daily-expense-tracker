# Daily Expense Tracker

A responsive web-based Daily Expense Tracker built using pure **HTML5** and **CSS3** (no JavaScript) to organize daily spending, validate expense inputs, and filter records by category.

## Features
- **Welcome Dashboard:** Displays total expenditure, total expense count, highest individual expense, and top spending category.
- **HTML5 Form Validation:** Enforces required fields, valid date selection, and positive amount values.
- **Category-wise Summary & Visual Chart:** Displays spending per category with pure-CSS horizontal progress bars.
- **Interactive Category Filtering:** Filters expense history rows by category using CSS `:checked` radio buttons and sibling selectors.
- **Responsive Design:** Adapts cleanly across desktop, tablet, and mobile screens using CSS Grid and Flexbox.
